# Arawaza Colombia · Brand Guidelines (web interactiva)

Guía de marca v1 de Arawaza Colombia en formato web: concepto, logo, color, tipografía, sistema gráfico, fotografía, estilo audiovisual, pilares de contenido y plan de activación de diciembre. **Solo una meta.**

> Propuesta para validar con Rubén Henao. Nada de esto está aprobado todavía.

## Ver en local

```bash
python -m http.server 5191
```

Abrir `http://localhost:5191`. Es HTML, CSS y JS sin compilación; GSAP, ScrollTrigger y Lenis se cargan desde jsDelivr.

## Estructura

- `index.html`: todas las secciones.
- `css/style.css`: variables de marca (`--aw-*`), componentes y responsive.
- `js/main.js`: movimiento (máscara de tinta, texto que se imprime, letras que suben, galería horizontal fija, parallax, contadores, probador de tipografía, tarjetas con inclinación).
- `img/logos/`: logos oficiales recortados del NAS de la casa matriz.
- `img/fotos/`: 12 imágenes de referencia generadas con Gemini (Nano Banana). Son de dirección de arte: las piezas finales usan fotos reales de atletas con su autorización.
- `fonts/`: Monument Extended y HK Gothic en WOFF2. **Sin licencia comercial todavía**: se compran cuando se apruebe la guía.
- `tex/tinta.png`: sprite de la máscara de tinta.
